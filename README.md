# Social Media Personality & Mood Predictor 🧠📱

This project uses machine learning to predict a user's **personality type** and **mood** based on their social media activity, such as likes, comments, shares, and mentions. It utilizes a **Random Forest Classifier** and includes interactive visualizations to showcase prediction results.

---

## 🔍 Project Overview

- **Input Features**:
  - Age
  - Gender
  - Likes per Post
  - Comments per Post
  - Shares per Post
  - Mentions per Post

- **Outputs**:
  - Predicted **Personality Type**: Introvert / Extrovert / Normal
  - Predicted **Mood**: Happy / Neutral / Sad
  - Visualization: Bar charts, Pie charts, and Heatmaps for prediction confidence

---

## 🧠 Model & Tools Used

- Random Forest Classifier (`sklearn`)
- Label Encoding & One-Hot Encoding
- Matplotlib & Seaborn for visualizations
- Jupyter Notebook (`.ipynb`)
- Dataset: `social_media_personality_dataset_with_mood_balanced.csv`
